# 火柴建築師 · 50 關企劃

## 核心規則
- 玩家是火柴建築師，每關是一張委託單（任務要求＋達成獎勵）。
- 用固定長度的火柴蓋建築：從錨點或火柴端點拖出，端點自動吸附，也能黏在別支火柴中段做斜撐。
- 建造時沒有重力；按「開始地震」後地面左右搖晃 10 秒。
- 過關：所有星星（高度／位置目標）都撐住，而且沒有任何膠點斷掉。不規定一定要用幾支。
- 計分：火柴越少越好。三星目標是實測過的最省參考解；≤ 目標 ×1.25 兩星；其他過關一星。
- 金幣：配額＝三星目標 ×2；每支火柴成本 1 金幣（開震時付款）；合格後沒用完的火柴每支換 2 金幣。
- 排行榜：每關比誰用的火柴最少，同支數先達成的排前面；另有金幣總榜。

## 難度曲線原則
- 每關大約只多 2–4 支火柴，一關只加一個新挑戰。
- 震度慢慢升：同一個震度連續 6–9 關才升一級。
- 每次升震度的第一關，建築先變小，讓玩家適應新的晃動。
- 不做橋，重點是地震。
- 震度順序：3 → 4 → 5弱 → 5強 → 6弱 → 6強 → 7。
